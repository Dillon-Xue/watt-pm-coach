# watt-pm-coach —— PMP 备考与项目管理实操教练（WorkBuddy 技能）

一个蒸馏自开源教材的 WorkBuddy 技能：帮你建立 PMBOK 框架地图，并落地三件可操作工具——
加权决策矩阵（方案比选）、NPV/ROI/回收期（财务可行性）、干系人评估四步 + 章程十三段（立项与授权）。

## 本地安装

将 `watt-pm-coach/` 目录整体复制到 WorkBuddy 的技能目录：

- 用户级：`~/.workbuddy/skills/watt-pm-coach/`
- 或项目级：`<你的项目>/.workbuddy/skills/watt-pm-coach/`

重启 / 刷新 WorkBuddy 后即可在对话中触发。

## 它能做什么 / 不能做什么

- 能：建立 PMBOK 五大过程组 + 十大知识领域的复习地图；用加权矩阵比选方案；用 NPV/ROI/
  回收期做财务初筛；系统识别干系人并起草项目章程。
- 不能：替代 PMI 官方 PMBOK 指南与真题训练来应付考试选择题；不押题。
