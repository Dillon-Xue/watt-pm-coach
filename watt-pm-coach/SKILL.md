# PMP 备考与项目管理实操教练

## 什么时候用它

- 你在备考 PMP，需要把 PMBOK 的五大过程组、十大知识领域串成一张可复习的地图；
- 面临多个方案要二选一（买 / 自建 / 外包），需要一套可比选的打分方法；
- 要论证一个项目值不值得做，需要 NPV、ROI、回收期这些财务判据；
- 接手新项目，要系统识别干系人、评估环境、起草项目章程。

## 核心判断

PMBOK 不是死记的清单，而是一套"先选对方向、再管好人、最后用章程锁定授权"的方法。书里最该带走的是三件可操作工具：加权决策矩阵（选项比选）、NPV/ROI/回收期（财务可行性）、干系人评估四步 + 章程十三段（立项与授权）。框架用来建立地图，真正上手靠的是这三件工具。

## 怎么做

**1. 用加权决策矩阵比选方案**
列出候选方案为行、关键需求 / 标准为列；给每列设权重（总和 100%）；逐格按满足程度打分（如 1–5）；加权求和 = 分数 × 权重，最高者胜出。特别适合"采购方案比选"这类多标准决策。

**2. 用 NPV / ROI / 回收期判项目财务可行性**
- NPV：把各期净现金流按折现率（常用 6%–14%）折成现值求和，再减初始投资。NPV>0 可接受，<0 否决，=0 看战略等其他因素。
- ROI：(总收益 − 总成本) / 总成本。>0 即盈利，越高越好（书中示例 52%）。
- 回收期：画累计收益与累计成本曲线，交叉点即回本时间点；越早回本风险越低。
- 三者一起看：NPV 看绝对增值、ROI 看效率、回收期看回本速度，互不替代。

**3. 干系人环境评估四步走**
识别全部干系人 → 弄清各自目标（含未明说的隐藏议程，手握权力者的目标重点关照）→ 界定真实问题（反复问"实际情况到底是什么"）→ 看文化差异（重点在沟通、谈判、决策三处；有些文化里"是"未必等于 yes）。

**4. 用关系建立六法稳住支持**
分析干系人（动机 / 雷点 / 角色 / 利益冲突）→ 评估影响力（权衡"高影响力者的冷淡支持"与"低影响力者的强力支持"）→ 摸清期望 → 提前定义各自的"成功" → 保持参与（别只汇报，要请教）→ 保持告知（每周一次状态更新通常最合适）。

**5. 用章程十三段锁定项目授权**
项目章程至少覆盖：①标识（项目名 / 日期 / 发起人 / 项目经理）②概述 ③目标（用 SMART：具体 / 可衡量 / 可接受 / 现实 / 有期限）④范围（含"不含什么"）⑤主要里程碑 ⑥主要交付物 ⑦假设 ⑧约束 ⑨商业需求 / 收益 ⑩初步成本 ⑪风险 ⑫章程签署 ⑬干系人（按职能 / 姓名 / 角色）。章程的作用是确立项目经理的职权与项目存在的理由。

## 判断标准

做对了会看到：方案比选有可追溯的打分依据；财务论证同时给出 NPV/ROI/回收期而非单一指标；干系人清单覆盖了"能影响项目的人"而不只是"我想通知的人"；章程在启动前就写清范围边界与职权。

做错了会看到：只凭感觉选方案、用 ROI 一个指标拍板、把干系人等同于"发邮件的名单"、章程写成空洞口号没有 SMART 目标与范围边界。

## 什么时候不该用它

- 它不能替代 PMI 官方 PMBOK 指南与真题训练来应付考试选择题——本技能帮你建立框架与实操手感，不押题。
- NPV / 回收期只是财务初筛，重大投资仍需完整商业论证与风险分析，别拿来当唯一决策依据。
- 书中的文化差异案例多来自欧美语境，落地到本地团队时要先校准沟通与决策习惯。
- 若你的组织已有固定章程 / Stage-Gate 模板，以组织模板为准，本十三段仅作查漏补缺。
- 想把一本书或长文蒸馏成技能包的，请用「一盏神灯」本身，不要用这个教练技能。
